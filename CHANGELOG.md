# Changelog

All notable changes to the MCPForge Marketing AI Prompt Pack.

## [1.0.0] — 2026-08-10

### Added
- **SEO Content Optimizer** — full keyword architecture, meta tag optimization, structured SEO report output
- **Social Media Campaign Planner** — 8-step campaign framework, content pillars, 30-day calendar, hook library
- **Email Sequence Writer** — sequence mapping, 5-step email framework, segmentation rules, deliverability checks
- **Landing Page Copywriter** — 7-section conversion architecture, above-fold, problem/solution, FAQs, final CTA
- **Ad Copy Generator (Google + Meta)** — RSA headlines/descriptions, sitelink extensions, Meta feed/carousel/video scripts, A/B test matrix
- **Brand Voice Architect** — voice DNA definition, spectrum sliders, writing mechanics, channel adaptations, banned words list
- **Content Calendar Strategist** — pillar architecture, content mix, 30-day calendar, repurposing system, editorial brief template
- **Analytics Report Narrator** — "So What? Now What?" framework, executive summary, channel narratives, ranked recommendations, watchlist
- Few-shot examples (3-5 per prompt, realistic input/output pairs)
- JSON Schema files for structured output (all 8 prompts)
- README with usage instructions for Claude, GPT-4, Cursor, and API integration
